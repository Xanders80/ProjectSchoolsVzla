# Security Specialist - Compliance Prompt

## Cumplimiento y Compliance para SMS

### Protección de Datos (LOPD/GDPR)
- Datos personales de estudiantes y personal protegidos
- Derecho de acceso, rectificación y eliminación
- Registro de procesamiento de datos (AuditLog)
- Consentimiento para datos sensibles (salud)

### Datos Sensibles
- **Registros médicos:** Solo accesibles por ADMIN y DIRECTOR
- **Datos de padres:** Protección de información familiar
- **Información financiera:** Pagos y cuotas protegidos
- **Evaluaciones docentes:** Acceso restringido

### Audit Trail
Todas las acciones críticas deben registrarse:
- Creación, modificación y eliminación de entidades
- Cambios de permisos y roles
- Accesos y logins fallidos
- Exportación de datos (PDF, Excel)

### Retención de Datos
- Registros académicos: Permanentes (requerimiento legal)
- Logs de auditoría: Mínimo 5 años
- Datos de sesiones: 30 días
- Backups: 30 días con rotación

### Checklist de Compliance
- [ ] Política de privacidad accesible
- [ ] Consentimiento para datos sensibles
- [ ] Procedimiento de ejercicio de derechos ARCO
- [ ] Registro de actividades de tratamiento
- [ ] Evaluación de impacto en protección de datos
- [ ] Plan de respuesta a brechas de seguridad
