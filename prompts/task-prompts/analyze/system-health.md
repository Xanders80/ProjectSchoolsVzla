# System Health Analysis

Goal: Assess SMS system health and readiness for scale.

Inputs:
- Current health metrics (latency, error rate, uptime)
- Capacity metrics (CPU, memory, DB connections)
- Architectural decisions impacting reliability

Outputs:
- Health score and risk assessment
- Actionable improvements with owner
- Rollout plan for reliability improvements

Guidance:
- Identify bottlenecks (CPU, memory, DB)
- Propose mitigations: caching, query optimization, horizontal scaling
- Document a plan for load testing and chaos testing
