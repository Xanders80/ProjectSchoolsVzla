# Generate Thymeleaf Template Prompt

Genera templates Thymeleaf para el SMS usando SB Admin 2.

## Input Requerido
- Nombre del template
- Módulo
- Tipo (list/form/view)
- Entidad y campos

## Output Esperado
- Template HTML completo
- Uso de fragments
- i18n con #{keys}
- DataTables si es lista
- Validación de formularios
