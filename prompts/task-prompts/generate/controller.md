# Generate Controller Prompt

Genera un controller Thymeleaf o REST para el SMS.

## Input Requerido
- Nombre del controller
- Módulo
- Entidad asociada
- Tipo (Thymeleaf/REST)
- Roles requeridos
- Endpoints necesarios

## Output Esperado
- Controller class con todos los endpoints
- Validaciones
- Mensajes i18n
