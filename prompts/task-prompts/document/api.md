# Document API Prompt

Documenta APIs del SMS con OpenAPI/Swagger.

## Formato
- Usar anotaciones @Operation, @ApiResponse, @Tag
- Describir cada endpoint
- Documentar request/response bodies
- Incluir ejemplos de uso

## Reglas
- Todos los endpoints públicos documentados
- Códigos de error documentados
- Roles requeridos especificados
- Ejemplos de request/response incluidos
