# Document Architecture Prompt

Documenta la arquitectura del SMS.

## Tipos de Documentación
1. Architecture Decision Records (ADRs)
2. Diagramas de componentes
3. Diagramas de secuencia
4. Diagramas de base de datos
5. API Documentation (OpenAPI)

## Formato ADR
```markdown
# ADR-XXX: Título

## Contexto
[Descripción del problema]

## Decisión
[La decisión tomada]

## Consecuencias
- Positivas: [...]
- Negativas: [...]

## Alternativas Consideradas
1. [Alternativa] - [Por qué no]
```
