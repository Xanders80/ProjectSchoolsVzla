# Refactor Code Prompt

Refactoriza código Java siguiendo las mejores prácticas del SMS.

## Técnicas de Refactorización
1. Extraer métodos largos
2. Reducir complejidad ciclomática
3. Aplicar patrones de diseño
4. Eliminar código duplicado
5. Mejorar nombres
6. Simplificar condicionales

## Reglas del SMS
- Constructor injection obligatorio
- Soft delete siempre
- Auditoría en entidades
- Interface + Implementation para servicios
- i18n para mensajes de usuario
